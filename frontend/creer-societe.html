Créer ma société

Environ 20 minutes, sur ordinateur. Vos données resteront dans votre propre compte Google : ni Orbia ni les autres sociétés n’y ont accès.

1. Créer le serveur

  1. Ouvrez script.google.com dans une fenêtre privée, connecté au compte Google de votre société.
  2. Cliquez sur Nouveau projet et nommez-le Orbia.
  3. Ouvrez le code du serveur, copiez tout, puis collez-le à la place du contenu de Code.gs. Enregistrez.
  4. Dans Paramètres du projet, cochez Afficher le fichier manifeste "appsscript.json". Revenez au code, ouvrez appsscript.json et remplacez son contenu par ceci :
{
  "timeZone": "Europe/Paris",
  "runtimeVersion": "V8",
  "exceptionLogging": "STACKDRIVER",
  "oauthScopes": [
    "https://www.googleapis.com/auth/script.external_request",
    "https://www.googleapis.com/auth/drive",
    "https://www.googleapis.com/auth/spreadsheets",
    "https://www.googleapis.com/auth/script.scriptapp"
  ],
  "webapp": { "executeAs": "USER_DEPLOYING", "access": "ANYONE_ANONYMOUS" }
}

2. Le relier à Orbia

Dans Paramètres du projet > Propriétés de script, ajoutez :

PropriétéValeur
ORBIA_GOOGLE_CLIENT_IDchargement…
ORBIA_BOOTSTRAP_ADMINvotre adresse Gmail : vous serez le premier administrateur

3. Autoriser et publier

  1. Dans le code, choisissez orbiaCheckSetup en haut, cliquez sur Exécuter et acceptez les autorisations. Google affiche un avertissement : c’est votre propre script, cliquez sur Paramètres avancés, puis Accéder à Orbia.
  2. Cliquez sur Déployer > Nouveau déploiement, choisissez Application Web, Exécuter en tant que : Moi et Qui a accès : Tout le monde, puis Déployer.
  3. Copiez l’adresse qui finit par /exec.
  4. Ajoutez une dernière propriété de script : ORBIA_PUBLIC_URL, avec cette adresse pour valeur.

Pour les mises à jour, utilisez toujours le crayon dans Gérer les déploiements, jamais un nouveau déploiement : l’adresse changerait.

4. Ouvrir votre société
